# ITTS – Guia do Administrador

O objetivo deste documento é a apresentação do módulo de administração da aplicação ITTS.

---

## 1. Autenticação

Para conectar-se como administrador, aponte seu navegador para a tela de autenticação do sistema. 
Na tela de autenticação, informe os dados de acesso do administrador. Após informar seus dados de acesso, selecione o botão **Entrar** para realizar o login no sistema. Se seus dados estiverem corretos a **Tela Inicial** do sistema será apresentada.

### 1.1 Tela Inicial

Ao acessar a interface de administração, as seguintes áreas estarão disponíveis:
- Barra superior: Atalhos para conta, notificações e ajuda;
- Menu de Navegação: Localizado à esquerda, permite acesso a todas as funcionalidades;
- Painel Central: Exibe o conteúdo da funcionalidade selecionada.

**Obtendo Ajuda**
Para obter ajuda, selecione o menu de usuário na barra superior e clique na opção **Ajuda**. O manual do sistema será apresentado.

**Alterando a Senha**
Para alterar sua senha, acesse o menu de usuário na barra superior e selecione **Alterar Senha**. Informe a senha atual, a nova senha e confirme a alteração.

## 1 - Dashboard
O Dashboard fornece uma visão geral do estado do sistema e do uso de recursos.
Para acessar, utilize o menu lateral e selecione a opção **Dashboard**. Nele, é possível monitorar o consumo de recursos da instância como:
- Consumo de CPU;
- Consumo de Memória;
- Consumo de Disco.

## 2 - Assinaturas
As assinaturas gerenciam o acesso dos clientes (tenants) à plataforma.

**Criando**
- No menu de navegação, selecione **Assinaturas**;
- Clique no botão **Adicionar**;
- Preencha as informações da assinatura;
- Selecione o botão **Salvar**.

**Atualizando**
- Na lista de Assinaturas, utilize o menu de **Ações** do registro desejado;
- Selecione a opção **Editar**;
- Realize as alterações necessárias e clique em **Salvar**.

**Clonando**
- Na lista de Assinaturas, utilize o menu de **Ações** do registro desejado;
- Selecione a opção **Clonar** e confirme a operação.

**Excluindo**
- Na lista de Assinaturas, utilize o menu de **Ações** do registro desejado;
- Selecione a opção **Excluir** e confirme a operação.

## 2 - Planos de Serviço
Os planos permitem definir valor, recorrência e limites de uso.

**Criando**
- Na guia Planos de Serviço, clique em **Adicionar**;
- Defina as configurações do plano;
- Selecione a opção **Salvar**.

**Atualizando**: 
- Na lista de Planos de Serviço, utilize o menu de **Ações** do registro desejado;
- Selecione a opção Editar;
- Altere os valores desejados;
- Selecione a opção **Salvar**.

**Excluindo**
- Na lista de Planos de Serviço, utilize o menu de **Ações** do registro desejado;
- Selecione a opção **Excluir** e confirme a operação.

## 3 - Personalização
Permite alterar a identidade visual da interface para o assinante.

**Preferências**
- Permite definir as informações da empresa parceira e logo.

**Cabeçalho**
- Permite personalizar o logo e cores do cabeçalho.

**Menu Lateral**
- Permite personalizar o esquema de cores do menu.

> Após realizar as alterações, clique no botão **Salvar**. As mudanças serão aplicadas imediatamente à interface.

A customização pode ser removida por meio do botão **Remover Customização**

## 4 – Configurações do Sistema

### Configurando um Tipo de Atividade
Os tipos de atividades definem ações que podem ser registradas no sistema.
- No Menu de Navegação, selecione **Configurações** e a guia **Tipos de Atividades**.
- Clique em **Adicionar**.
- Informe o Módulo, Nome, Descrição e se está Ativo.
- Clique em **Salvar**.

### Atualizando/Excluindo Tipos de Atividades
- Na relação de tipos de atividades, selecione o botão **Ações** para o registro desejado.
- Escolha **Editar** para modificar ou **Excluir** para remover o registro.
